AUDIO FOLDER
============

Put your letter-sound recordings in this folder as .mp3 files.

By default, questions.js expects files named:

  question01.mp3
  question02.mp3
  question03.mp3
  ...
  question50.mp3

Each file should contain a short recording of a single letter SOUND
(the phonics sound, like /f/), not the letter's name (not "eff").

No audio files are included in this project — this folder is
intentionally empty (aside from this note) so you can drop in your
own recordings. Until you add files, "Play Sound" simply won't play
anything (the app won't crash — it fails silently), so you can still
test the quiz's look and logic before recording audio.

If you want to use different filenames, just update the "audio"
field for the matching question inside questions.js.
